### Bitwise AND (`&`)

> **Rule:** `&` gives `1` only when **both bits are `1`**.
>
> ```text
> 1 & 1 = 1
> 1 & 0 = 0
> 0 & 1 = 0
> 0 & 0 = 0
> ```
>
> **Example:**
>
> ```text
> 54321 = 1101 0100 0011 0001
>     6 = 0000 0000 0000 0110
>         -------------------
>  &      0000 0000 0000 0000
> ```
>
> Therefore:
>
> ```text
> 54321 & 6 = 0
> ```
>
> So the result is **0 → 0th index/bucket**.
>
> **HashMap formula:**
>
> ```text
> index = hash & (capacity - 1)
> ```
>
> If capacity = `8`:
>
> ```text
> index = 54321 & 7
>       = 1
> ```
>
> So the object goes to **index 1**.
